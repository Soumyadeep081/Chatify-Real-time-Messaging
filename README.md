# Chat & Trending Discovery Platform

A real-time chat application with an integrated **Trending discovery section** that allows users to explore current events, viral topics, and discussions across categories such as sports, news, movies, and technology.

Users can browse trending content, share topics directly in chats, bookmark important posts, and react or participate in discussions around popular events.

The goal of this project is to combine **real-time communication and trend discovery** to make exploring global topics more interactive and engaging.


## Installation & Running

### 1. Clone the Repository
```bash
git clone https://github.com/Soumyadeep081/Chatify-Real-time-Messaging.git
cd Chatify-Real-time-Messaging
```

### 2. Install Dependencies

Frontend (Next.js)

```bash
cd frontend
npm install
```

Backend (InferForge)

```bash
cd backend
npm install
```

### 3. Configure Environment Variables

Create a `.env` file and add the required configuration:

```env
DATABASE_URL=your_database_url
API_KEY=your_api_key
JWT_SECRET=your_secret
```

### 4. Run the Application

Start Backend

```bash
cd backend
npm start
```

Start Frontend

```bash
cd frontend
npm run dev
```
