# Scripts Directory

This directory contains consolidated scripts for maintenance, fetching data, and testing.

## Consolidated Files

- `fetch_js.js`: All JavaScript fetch scripts.
- `fetch_py.py`: All Python fetch scripts.
- `fix_js.js`: All JavaScript fix scripts.
- `fix_py.py`: All Python fix scripts.
- `test_js.js`: All JavaScript test scripts.
- `scripts_ps1.ps1`: All PowerShell scripts.

## How to use

Individual scripts are wrapped in IIFEs (for JS) or separated by comments. You can run the entire file or copy a specific block to run it independently.
